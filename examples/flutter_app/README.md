# bd_offline_geocoder_example

Flutter example app for `bd_offline_geocoder`.

The app loads the real ADM1-ADM4 GeoJSON files from the package assets using
`BangladeshBoundaryAssets`, accepts latitude/longitude input, and displays the
matched Bangladesh administrative address.

Run it with:

```sh
flutter pub get
flutter run
```

From the repository root:

```sh
cd examples/flutter_app
flutter pub get
flutter run
```
