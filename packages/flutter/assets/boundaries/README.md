# Bangladesh Boundary Assets

This package bundles real Bangladesh administrative boundary GeoJSON files:

- `bgd_admin1.geojson` - ADM1 divisions
- `bgd_admin2.geojson` - ADM2 districts
- `bgd_admin3.geojson` - ADM3 upazilas/thanas/city corporations
- `bgd_admin4_simplified.geojson` - simplified ADM4 unions/wards/pourashavas

Source repository:

https://github.com/meetshaks/bangladesh-administrative-boundaries-json

The source repository documents ADM1-ADM3 as derived from HDX/OCHA COD-AB
Bangladesh data and ADM4 as derived from geoBoundaries. Keep the original data
licenses and attribution requirements in mind when publishing an app that bundles
these files.
