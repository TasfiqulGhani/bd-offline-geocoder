# Third-Party Notices

This package bundles Bangladesh administrative boundary data from:

https://github.com/meetshaks/bangladesh-administrative-boundaries-json

The source repository documents:

- ADM1-ADM3 boundary files as derived from HDX/OCHA COD-AB Bangladesh data.
- ADM4 simplified boundaries as derived from geoBoundaries.

Bundled files:

- `assets/boundaries/bgd_admin1.geojson`
- `assets/boundaries/bgd_admin2.geojson`
- `assets/boundaries/bgd_admin3.geojson`
- `assets/boundaries/bgd_admin4_simplified.geojson`
